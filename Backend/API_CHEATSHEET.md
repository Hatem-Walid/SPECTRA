# API Cheat Sheet — AI Console Backend

Base URL (dev): `http://localhost:8000`
Interactive docs (auto-generated by FastAPI): `http://localhost:8000/docs`

---

## `GET /health`
Sanity check that the server is up.

**Response**
```json
{ "status": "ok" }
```

---

## `POST /predict/regression` — Insurance Cost

**Request** (`application/json`)
```json
{
  "age": 35,
  "sex": "male",
  "bmi": 27.5,
  "children": 2,
  "smoker": "no",
  "region": "southeast"
}
```

| Field | Type | Allowed values |
|---|---|---|
| age | int | 0–120 |
| sex | string | `male`, `female` |
| bmi | float | 10–60 |
| children | int | 0–10 |
| smoker | string | `yes`, `no` |
| region | string | `southwest`, `southeast`, `northwest`, `northeast` |

**Response**
```json
{ "predicted_charges": 8234.50 }
```

---

## `POST /predict/classification` — Network Intrusion

**Request** (`application/json`) — ⚠️ field names below are placeholders; swap for the actual feature shortlist once trained.
```json
{
  "duration": 0,
  "protocol_type": "tcp",
  "service": "http",
  "flag": "SF",
  "src_bytes": 181,
  "dst_bytes": 5450,
  "count": 8,
  "srv_count": 8,
  "same_srv_rate": 1.0,
  "dst_host_srv_count": 9
}
```

**Response**
```json
{ "prediction": "normal", "confidence": 0.94 }
```
`prediction` is one of: `normal`, `dos`, `probe`, `r2l`, `u2r`.

---

## `POST /predict/image` — Leaf Disease

**Request** (`multipart/form-data`, not JSON)
```
file: <image binary>
```

**Response**
```json
{
  "prediction": "Bacterial Spot",
  "confidence": 0.89,
  "top_3": [
    { "label": "Bacterial Spot", "confidence": 0.89 },
    { "label": "Healthy", "confidence": 0.07 },
    { "label": "Downy Mildew", "confidence": 0.04 }
  ]
}
```

## Error shape (all endpoints)

Any failure returns HTTP 4xx/5xx with:
```json
{ "detail": "human-readable error message" }
```
The frontend's `api.js` already reads `detail` and surfaces it in the error state.

---

## Where to plug in real models

Everything model-related lives in `backend/models.py`, isolated from the API layer:

| Function | What to replace |
|---|---|
| `load_insurance_model()` | ✅ Done. Loads `saved_models/insurance_preprocessor.joblib` (ColumnTransformer: MinMaxScaler on age/bmi/children + OneHotEncoder on sex/smoker/region → 11 features) and `saved_models/insurance_nn.keras` (Keras NN, 11 → 1). Requires `dill` installed — see requirements.txt. |
| `load_intrusion_model()` | Loads `saved_models/intrusion_model.joblib` + `intrusion_label_encoder.joblib` — the encoder maps predicted class index back to `normal`/`dos`/etc. |
| `load_leaf_model()` | Loads `saved_models/leaf_model.h5` — a Keras model; update `_leaf_classes` to match `train_generator.class_indices` order exactly |

Drop the three files in `backend/saved_models/` and the API works as-is — no changes needed in `main.py`.
